# 課程資料後台（Google 試算表 + Google Drive）

網站上的問卷、課堂互動、出場券、練習紀錄與錄音，會送到老師的 Google 試算表，錄音檔存進 Google Drive。後台由 Google Apps Script 接收資料，不需要另外架伺服器。

## 會收到哪些資料

| 試算表分頁 | 內容 |
| --- | --- |
| 學員名單 | 姓名、科系、首次登錄與最後活動時間、送出次數 |
| 第一堂課前問卷（入班問卷）等 | 每份問卷一個分頁，一列一位學員，一欄一題 |
| 互動紀錄 | 選擇題作答、排序遊戲、音準挑戰、吐氣前測與後測、作業勾選、歌詞換氣標記、舉手計票、分組計分 |
| 出場券 | 3-2-1 出場券的三個回答 |
| 練習紀錄 | 七天呼吸紀錄表 |
| 錄音 | 錄音名稱、長度與 Drive 檔案連結（檔案存在「流行歌唱班_學員錄音／第 N 堂」資料夾） |

學員第一次送出資料時，需要填寫姓名、科系與「課程代碼」。課程代碼只存在 Apps Script 的設定裡，不在公開的網站原始碼中，用來擋掉非本班的送出。

## 安裝步驟（約 10 分鐘，只需做一次）

1. 開啟 Google 試算表「流行歌唱班｜課程資料後台」：
   https://docs.google.com/spreadsheets/d/1R47vwh5dsi4gYebZoIr1htCXLP4zvTA55AuBnv1PsBw/edit
2. 點選單「擴充功能 → Apps Script」，開啟程式編輯器。
3. 刪除編輯器裡原本的內容，貼上本資料夾的 `apps-script/Code.gs` 全部內容，按「儲存」。
4. 左側「專案設定」（齒輪）→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，回到編輯器開啟 `appsscript.json`，貼上本資料夾的 `apps-script/appsscript.json`，儲存。這一步會把時區設為台北。
5. 在編輯器上方的函式選單選擇 `setup`，按「執行」。第一次執行會要求授權：選擇你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是因為程式需要寫入試算表與建立 Drive 資料夾。
6. 回到試算表重新整理，會看到各個分頁與新的「歌唱班後台」選單；課程代碼預設為 `PIXEL2026`，可從「歌唱班後台 → 設定課程代碼」修改。
7. 回到 Apps Script，點右上「部署 → 新增部署作業」：
   - 類型選「網頁應用程式」
   - 執行身分：「我」
   - 誰可以存取：「所有人」
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）
8. 把網址填進網站的 `assets/config.js`：

   ```js
   window.PIXEL_CONFIG = {
     endpoint: 'https://script.google.com/macros/s/……/exec'
   };
   ```

   推送到 GitHub 後，網站就會開始把資料送進試算表。網址也可以直接交給 Claude 代為填入。

## 日後修改程式

修改 `Code.gs` 後，需要「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會改變。

## 隱私與注意事項

- 試算表與錄音資料夾只有老師本人能開啟；錄音檔不會公開分享。
- 學員在網站上的資料（姓名、科系、課程代碼、尚未送出的紀錄）存在各自的瀏覽器。共用電腦時，可在「學員資料」視窗按「換人使用」清除。
- 網路中斷或後台尚未設定時，資料會先存在學員的瀏覽器，連線後自動補送。
- Apps Script 每天有執行次數與總時間的免費額度，一個班級的使用量遠低於上限。
