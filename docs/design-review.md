# Pixel Studio 視覺改版與驗證

驗證日期：2026-10-06。改版在本機專案完成，尚未發布到 GitHub Pages。

## 設計方向

以「每一個聲音，都有自己的形狀」為核心，把網站設計成可探索的聲音實驗室。墨綠背景、暖白文字、萊姆色重點，搭配大尺度中英文排版、細線分隔與課程編號。原有 Pixel Studio 彩色標誌保留在工作坊介紹；各堂課的色彩仍用來辨識課程與教學階段。

首頁提供課程、講義、問卷與練習入口。SVG 聲波可透過頻率滑桿改變，聲音由瀏覽器 Web Audio 即時產生，不下載音檔，也不存取麥克風。聲音需按鈕啟動，12 秒後自動停止；離開頁面或切換到背景也會停止。播放中的視覺呼吸動畫尊重減少動態效果偏好。

講義與問卷採同一套設計變數。投影片保留既有內容、換頁與互動邏輯，調整背景、元件邊框與品牌色。列印版與 PDF 未修改。

評估方向參考 [Webby Awards 官方網站評審標準](https://www.webbyawards.com/judging-criteria/) 的內容、導航、視覺、功能、互動及整體體驗。這份紀錄是工程與設計自查，沒有將自評分數當成獎項評審結果。

## 三輪修整

1. 重建首頁敘事、課程入口與聲波互動；渲染桌面完整頁面與手機畫面，檢查資訊層次。
2. 檢查四種尺寸，修正講義長字串換行、320px 投影片六組圓形圖表溢出、問卷過寬，以及學員資料視窗配色。校正音準與錄音入口，連到實際互動投影片。
3. 重新驗證頁面尺寸、互動狀態、教材載入與本機連結，並檢視修整後的問卷及音準課堂畫面。

## 目前的限制

- `assets/config.js` 的 Apps Script endpoint 原本即為空白。首頁文字已調整，問卷原有未連線提示仍會顯示；尚未驗證實際回傳老師試算表。
- 本次沒有操作真實麥克風，也沒有提交測試問卷或上傳錄音。
- 第三至第六堂投影片仍維持「準備中」；六堂講義與問卷入口均保留。
- 尚未執行真實 iOS / Android 裝置或 Safari 的驗證。桌面自動化工具無法啟用 Chrome，因此採用無介面 Chrome 渲染與檢查。
