發聲 Pronunciation

第四堂：五個母音與子音咬字，讓每個字都聽得清楚。

戴意誠（1998）：人聲三大要素為呼吸、共鳴與發聲。呼吸是動力，共鳴是擴音器，發聲決定聽眾聽到什麼字。

互動手指投票
承00:20–00:55　一、何謂共鳴

共鳴，是歌聲的擴音器

共鳴最簡單的定義：物體因共振而發聲。

聲帶發出的原始聲音，就像一根單獨的琴弦，微弱又單薄；要借助身體腔體的共振，才會變成響亮、有持續力的歌聲。

投票後，老師用吉他實際示範：按住琴身與放開琴身，聲音差多少。

吉他如果只剩琴弦、沒有琴身，聲音會怎樣？

  1. 變得更大聲
  2. 幾乎沒有改變
  3. 微弱、單薄，很快消失
  4. 音高變高
琴身就是吉他的共鳴箱。音高由琴弦決定，音量與音色則靠共鳴箱放大；人聲的共鳴箱是口腔、頭腔與胸腔。
互動提取練習・翻牌
承二、三個共鳴腔

三個共鳴腔，在身體的哪裡？

頭腔共鳴：在哪裡？怎麼找？
顎以上至眉心、前額、頭頂閉嘴哼 /m/，鼻樑與眉心發麻。音色柔和華麗；小心變成擠鼻子的鼻音。
口腔共鳴：在哪裡？怎麼找？
顎以下、聲帶以上打哈欠時軟顎上提、口腔後方打開。音色清脆明亮；小心把「打開」誤解成用力擠。
胸腔共鳴：在哪裡？怎麼找？
聲帶以下的胸腔手掌貼胸口，低音說「嗯哼」。音色渾厚實在；小心往下壓喉製造「假厚」。

承四、口腔共鳴｜清脆明亮

打開口腔：是「撐開」，不是「擠開」

這樣做

先假裝打哈欠，記住口腔後方那個「大空間」：軟顎上提、舌根放鬆、下巴自然垂下。

保持這個空間，再以「哈」輕輕嘆氣。

常見錯誤

把喉嚨「張開」誤解為用力擠壓，脖子青筋浮起，聲音僵硬、卡喉。

台語歌的 /a/、/o/ 母音開口大，正好練習打開感。

互動預測—觀察—解釋・共鳴觀測站
承五、共鳴的轉換｜胸腔 → 頭腔

從胸腔滑到頭腔，音高和音量怎麼變？

  1. 先預測：音高往上時，音量會變大還是變小？
  2. 按「開始錄製」，以 /m/ 或 /u/ 從胸腔的低音，慢慢滑到頭腔的高音
  3. 看兩條曲線：黃線是音高，藍色是音量
  4. 在圖上拖曳選一段，標記胸腔、口腔或頭腔
  5. 下載觀測圖，或上傳給老師

共鳴由胸腔移到頭腔，頻率升高，音量（振幅）會明顯變小。這是正常的：過換聲區時音量收小、口腔保持打開，讓兩種聲音逐漸交接，不要用更大的力氣硬推。

互動自我評量・錄音對照
承頭腔共鳴 ≠ 鼻音

捏鼻測試：你的聲音卡在鼻子嗎？

  • 唱一個舒服的長音 /a/，先錄「不捏鼻」
  • 同一個音再唱一次，唱到一半捏住鼻子
  • 兩段一起聽：聲音明顯變悶，代表氣流走了鼻子，形成鼻音
  • 聲音幾乎不變，共鳴位置就是對的

嘴巴再打開一點、軟顎上提，想像聲音從眉心往前送出，而不是從鼻孔擠出來。

① 不捏鼻

② 捏鼻

承六、胸腔共鳴｜渾厚實在

手掌貼胸口，感覺低音的振動

這樣做

以說話的音高往下三個音，發出 /hei/ 或低聲說「嗯哼」。

手掌感受到胸口振動，就是胸腔共鳴。像對著一個人說心事，不必用力。

常見錯誤：假厚

把喉嚨往下壓，製造「很低沉」的聲音。

聽起來厚，其實喉嚨很緊，高音會上不去，唱久了也容易累。

轉01:05–01:40　找出換聲區

警笛滑音：曲線在哪裡斷掉？

  • 以 /u/ 或 /ng/，從最低音慢慢滑到最高音，再滑回來
  • 像救護車的警笛，中間不要停
  • 聲音突然斷掉、音色轉變的地方，就是換聲區
  • 聽到轉變的瞬間按「標記換聲點」，再用鍵盤確認是哪個音

紅點是可能的換聲點。曲線跳動也可能是麥克風收音，以你自己聽到的轉變為準。

互動提取練習
轉七、共鳴的混合使用

三種共鳴，一起用、比例不同

沒有頭腔潤飾，聲音乾硬；缺少胸腔支撐，音色虛浮。

過換聲區的三個訣竅

① 音量稍微收小
② 口腔保持打開
③ 讓胸腔與頭腔逐漸交接，不要用更大的力氣硬推

唱到高音區時，比例較高的是哪一種共鳴？

  1. 胸腔共鳴
  2. 口腔共鳴
  3. 頭腔共鳴
  4. 高音不需要共鳴
高音區較多利用頭腔共鳴，低音區偏重胸腔，口腔則一路保持打開。用胸腔硬推高音，就是破音與喊叫的開始。
