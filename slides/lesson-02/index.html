肺活量確實有個別差異，課堂上的秒數差距，多半來自吸氣的方式與吐氣的控制：

吸進胸口上方，氣息很快就用完；吸到腰腹一圈，再由腹部慢慢推送，秒數就會拉長。今天下課前，我們以後測驗證。

互動排序遊戲
承00:20–00:55　一、歌唱發聲的原理

一個聲音，從腰腹走到嘴巴

挑戰：將七個環節，依照「氣流前進的順序」排列。

任何一個環節緊繃，整條路徑都會受到影響。歌聲與說話同樣來自發聲，歌聲的音域更寬、持續時間更長，也更仰賴氣息的穩定供應。

互動即時回饋・音準挑戰
承二、聆聽的重要性

音準聽清楚，才能唱準確

音準 Pitch：「五音不全」多半是耳朵尚未經過訓練，發聲器官本身並無問題。

音色 Tone：錄下自己的歌聲並重複聆聽，是訓練辨聲最直接的方法。

先聆聽、再思考、再演唱：播放目標音 → 在心裡哼唱一次 → 再發出聲音，觀察指針是否落在綠色區間。

承三、歌唱的姿勢

站姿正確，氣息才進得來

部位正確姿勢常見錯誤
雙腳與肩同寬，重心微微向前三七步、重心放在腳跟
膝蓋微微放鬆，避免鎖死膝蓋往後頂直
肩膀放鬆下沉，吸氣時保持不動縮肩、聳肩
胸口自然打開駝背或過度挺胸
頭頸下巴與地面平行，眼睛平視前方仰頭追高音、低頭看譜
臉部下顎放鬆，口腔內部打開咬牙、皺眉
承吉他社專屬

自彈自唱的坐姿

  • 坐在椅子前三分之一，骨盆坐穩
  • 吉他貼近身體，上身避免往前趴
  • 譜架與視線同高
  • 和弦先練到無需看手，再開始自彈自唱

坐姿的重要性

吉他手最容易低頭看指板。
頸部一彎曲，喉嚨也跟著受到壓迫，
高音更難唱上去，氣息也更短。

迷思還是事實？先舉手猜測，再翻牌揭曉

喉嚨乾燥時，喝冰水最舒服
迷思冰水讓喉部肌肉收縮，溫水才能滋潤聲帶。
說悄悄話可以讓聲帶休息
迷思耳語反而讓聲帶緊繃，有效的休息方式是暫停說話。
唱歌前喝牛奶可以潤喉
迷思牛奶、巧克力容易生痰，演出前三小時應避免。
每天喝 1,500 到 2,000 c.c. 溫水
事實黏膜保持滋潤，聲帶才能順利振動；少量多次飲用。
喉嚨卡卡時，就用力咳一下
迷思改用吞口水的方式，用力咳嗽會撞擊聲帶。
唱完 Ktv 隔天沙啞很正常，可以不理會

承六、胸腹式呼吸

雙手叉腰，感受腰間一圈「游泳圈」

歌唱呼吸以小腹肌肉為基礎，又稱為丹田呼吸、橫膈膜呼吸或腹式呼吸，重點都在胸腹結合。

照鏡子或請隔壁同學觀察：肩膀上抬，代表氣息吸進了胸口上方。

吸氣時，哪一個現象代表氣息吸對了位置？

  1. 肩膀往上抬
  2. 胸口鼓起來
  3. 腰的前、側、後一圈擴張
  4. 肚子用力往內縮
吸氣時，腰圍一圈往外擴張，肩膀與鎖骨保持不動；吐氣時，腰腹再慢慢收回。

三組肌肉訓練，各四小節

/s/

腹部肌力

發出氣音，四小節之後，腹部應有緊繃感。

/hei/

喉部肌力

發出低音，提升低音音準的控制力。

/hu/

綜合訓練

一小節低音、一小節假音交替。

快吸快吐時，如果吸氣聲太大，代表使用了太多喉嚨的力氣，請放鬆喉部，改由腹部帶動。

轉九、呼吸延長訓練

讓每一口氣使用得更久

快吸慢吐

/s/ 吐氣到底時，以手輕壓腹部，再快速吸氣。
改以 /i/ 吐氣，可以同時訓練腹肌。

快吸停吐

吸足之後，屏住氣息讀秒，再吐氣。
每一次都延長讀秒的時間。

唱到一半才找氣，最常出現什麼結果？

  1. 音量變大
  2. 句尾無力、拖拍
  3. 音更準
  4. 沒有影響
氣息不足時，句尾會無力、拖拍，甚至在不該斷開的字中間斷開。先標好換氣點，再開口演唱。
