互動排序遊戲
承00:20–00:55　一、歌唱發聲的原理

一個聲音，從腰腹走到嘴巴

挑戰：把七個環節依照「氣流前進的順序」排好。

任何一個環節緊繃，整條路徑都會受到影響。歌聲與說話同樣來自發聲，但歌聲的音域更寬、持續時間更長，也更仰賴氣息的穩定供應。

互動即時回饋・音準挑戰
承二、聆聽的重要性

聽得準，才唱得準

音準 Pitch：「五音不全」多半是耳朵尚未訓練，發聲器官本身並無問題。

音色 Tone：錄下自己的歌聲重複聆聽，是訓練辨聲最直接的方法。

先聽、再想、再唱：播放目標音 → 在心裡哼一次 → 再發出聲音，看指針是否落在綠色區間。

承三、歌唱的姿勢

站好，氣才進得來

部位正確常見錯誤
雙腳與肩同寬，重心微微向前三七步、重心放在腳跟
膝蓋微鬆，不鎖死膝蓋往後頂直
肩膀放鬆下沉，吸氣時不上抬縮肩、聳肩
胸口自然打開駝背或過份挺胸
頭頸下巴與地面平行，眼睛平視前方仰頭追高音、低頭看譜
臉部下顎放鬆，口腔內部打開咬牙、皺眉
承吉他社專屬

自彈自唱的坐姿

  • 坐在椅子前三分之一，骨盆站穩
  • 吉他貼近身體，不往前趴
  • 譜架與視線同高
  • 和弦先練到不必看手，再開始自彈自唱

為什麼？

吉他手最容易低頭看指板。
頸部一彎，喉嚨也跟著受壓，
高音更上不去、氣也更短。

承六、胸腹式呼吸

雙手叉腰，感受一圈「游泳圈」

歌唱呼吸以小腹肌肉為基礎，有人稱為丹田呼吸、橫膈膜呼吸或腹式呼吸，重點都是胸腹結合。

照鏡子或請隔壁同學看：肩膀上抬，代表氣吸進了胸口上方。

吸氣時，哪一個現象代表氣吸對了位置？

  1. 肩膀往上抬
  2. 胸口鼓起來
  3. 腰的前、側、後一圈擴張
  4. 肚子用力往內縮
吸氣時腰圍一圈往外擴張、肩膀與鎖骨不動；吐氣時腰腹再慢慢收回。

綜合訓練

一小節低音、一小節假音交替。

快吸快吐時若吸氣聲太大，代表用了太多喉嚨的力氣，請放鬆喉部，改由腹部帶動。

唱到一半才找氣，最常出現什麼結果？

  1. 音量變大
  2. 句尾無力、拖拍
  3. 音更準
  4. 沒有影響
氣不夠時，句尾會無力、拖拍，甚至在不該斷的字中間斷開。先標好換氣點，再開口。
